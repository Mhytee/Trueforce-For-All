The plugin ships in several languages, and any language can be translated from inside it. What you type shows up in the plugin as you go, and what you write reaches everyone else using that language.

## Choosing a language

On the **Settings** tab, open **Language** and pick one under **Panel language**. A language that is only partly done still shows: everything translated appears in it, and the rest stays in English.

**Automatic** follows your Windows display language, and only switches once that language is mostly translated, so nobody is moved into a half-finished one without asking.

## Translating

Press **Translate…** to open the editor, with the English on one side and your language on the other. Type into a row and leave it, and the plugin behind the window changes straight away. A row left empty keeps the English.

To start a language nobody has done yet, press **Translate a language…** and pick it, or type its code, like pt-BR, if it is not in the list. Set its **Language name** too, as the language writes it, so the list shows it properly.

While you work:

- **One at a time** goes through the strings singly, most used first. Enter saves and moves on, and **Skip** leaves one in English for now.
- The search box finds a string by its English, by what you wrote, or by its key.
- Placeholders like {0} stand for a number or a name filled in later. Keep every one, or that row falls back to English.
- A row too long for the space it sits in is marked, with roughly how many characters fit.

## Sharing it

With community features on, a row is sent a few seconds after you finish it, and anything written offline goes up the next time the window opens. Everyone using that language gets it within about a day, with no account and no plugin update. An account only puts your name in the credits.

To pick up other people's fixes yourself, keep **Apply translations other people have sent** on. Anything you wrote yourself still wins over theirs.

## The files

Each language is one file in the languages folder, and **Open the folder** shows you where. A file you edit there wins over the one the plugin ships, and the plugin picks up a save without restarting SimHub.

The guides, this one included, are still in English.
