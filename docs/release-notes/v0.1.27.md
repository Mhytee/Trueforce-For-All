The plugin now has a public beta channel. This release adds the opt-in, a safety net around it, and better release-notes rendering.

### Try the beta channel

- **New in Settings: "Get beta (pre-release) updates in-app".** The next generation of the plugin (community preset sharing, telemetry-based force feedback for the Forza titles, rev lights, new effects, and more) is being tested in the open as 0.2.x pre-releases. Turn the toggle on and the in-app updater offers you the newest beta like any other update. Turn it off any time to go back to stable releases only.
- **Your presets and settings are backed up before your first beta install.** Beta builds migrate your data forward, so this release snapshots everything just before the crossing. If you later switch back to stable from a beta build, the updater offers to restore that snapshot, and you land exactly where you left off.

### Bug fixes

- **Release notes render properly in-app.** Warning callouts and links in GitHub release notes used to show as raw markdown in the update window; they now render like they do on GitHub, so a beta's release notes read correctly before you decide to install it.
