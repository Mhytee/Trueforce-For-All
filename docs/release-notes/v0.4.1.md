# v0.4.1: Wheels that switched themselves off and on now stay on

### Your wheel stops power cycling

On v0.4.0 the plugin could mistake a healthy wheel for one whose force feedback
capture had failed, and switch its USB port off and on to repair it. The check
ran before the capture had finished starting up, so it found nothing for the
simple reason that nothing had started looking yet. It now waits for the capture
to actually be running before it decides anything, and there is a switch for it
in Settings, Force Feedback (Advanced), if you would rather it never did that.

### Clearer answers when USBPcap will not start

USBPcap is what lets the plugin read your game's force feedback. When it is
missing the plugin now says so, with a button to install it, instead of leaving a
line of text inside a collapsed panel. When it is installed but never loads, the
self-test now tells you which of the two causes you have, and a new Uninstall
button gives you the repair that was missing: reinstalling over a broken USBPcap
does nothing, because its installer stops as soon as it finds an existing
install.
