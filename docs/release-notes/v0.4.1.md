# v0.4.1: Usage report carries two language codes

### Privacy

- The anonymous usage report now includes two language codes, each two letters: the language Windows is displayed in and the language of your Windows regional format setting, such as "en" or "de". They are there so translating the plugin can start with the languages people actually read. Neither code carries a region and neither can identify you. Clearing "Share anonymous usage statistics" in Settings still turns the whole report off, including this.
