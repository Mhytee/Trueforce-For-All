> [!WARNING]
> **Installing this pre-release enrolls you in the beta channel.** Beta updates are open to everyone: future pre-releases arrive through the in-app updater with no sign-in or Patreon needed, and you can leave the channel any time in Settings > Updates.
>
> If you are on v0.2.0 or v0.2.1 without a linked Patreon, those older builds still gate the in-app channel: install this one manually and you are on the open channel from here on.

A small compatibility release so switching back to stable works for everyone.

### Bug fixes

- **The pre-beta backup format is now shared across plugin generations.** Stable v0.1.27 backs up your presets and settings before your first beta install; this build's switch-back restore understands that backup (as well as the one v0.2.2 wrote), so returning to the stable release puts everything back where the stable build expects it.
